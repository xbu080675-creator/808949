# Multimodal Engine v0.3.0 / Tavo Multimodal v0.0.21

实验版本：修复长视频采样提前停止，增加前台服务任务、锁屏 CPU 唤醒（最长2小时持锁）、实际单元进度、粗略 ETA、通知栏取消、完成提醒、私有目录原子检查点、手动恢复、Whisper Base/Small 模型切换。保留 ML Kit 图像标签与此前 MCP 连接。完整视觉语言模型未集成；不会将标签冒充视觉语言理解。

- 新 APK 未在开发环境编译（无 Android SDK/NDK）；GitHub Actions 编译、签名、Whisper 原生库检查结果待确认。

## 任务
1. 启动 Engine MCP，允许通知；Tavo 原有 Streamable HTTP 地址与 Bearer token，脚本调用 MCP 工具权限必须开启。
2. 模型页可选择 Base（148 MB，兼容旧模型下载记录）或 Small（488 MB）。下载和校验独立，使用前校验固定版本 SHA-256。模型固定为任务创建时的选择，恢复不换模型。Small 未实机验证。
3. 任务页选择系统文件选择器中的音视频。必须获得持久 URI 读取授权；最长媒体2小时。最多96个均匀视觉采样点遍历全时长，重复画面筛选同时保留时间轴锚点；不等于逐帧分析。音频按30秒窗口 seek/解码/重采样/Whisper，时间戳近似，每段记录成功/失败。无权重时明确跳过音频，不声称完整识别；单次转录文字上限400000字符，超限段记录失败。
4. 分析由 Engine 前台服务拥有，可切换应用，持有有时限 partial wake lock，系统强杀/重启/文件权限撤销仍可能中断；锁屏运行须手机验证。允许通知后可看进度、取消和完成提醒；进度=实际完成的处理单元/计划单元（失败单元也计已处理，并记录失败，跳过的音频不计完成），ETA 根据已处理单元平均耗时估算，跨阶段可能不准。取消在当前原生分段退出后生效。
5. 最近一次任务检查点在应用私有目录；显式点击继续中断任务从下一已保存单元恢复，未完成单元会重做。源文件必须仍可读、未变化。仅保存最近任务，不是多任务历史；可清除记录。完成后授权 MCP 读取；授权不持久化。
6. Tavo 高级诊断 → 查询本机任务进度（按需调用，官方 MCP 调用可能要求确认，不进行自动轮询）/ 导出本机媒体任务报告 / 授权分析结果注入下次回复。报告过长时可选择两分钟区间；发送给聊天服务的是分析文字，原始媒体留本机。自动跨应用提交和 VLM 尚未完成。长报告受宿主传输长度限制，未验证极限。
7. 测试建议使用已测过的345.110秒视频。时间轴算法计划70个采样点，最后342.644秒，12个音频窗口。分析中切回 Tavo、锁屏、观察通知、取消再恢复，检查报告最后时段、音频分段状态与分析文字。此例算法测试不是实机分析结果。

## 验证
本地 JDK 编译纯 Java Timeline 和 MCP 核心；时间轴、窗口边界、时间戳偏移、进度/ETA 断言通过；实际 HTTP 12项断言通过（状态、取消供应者模拟）；TPG 语法、旧功能回归、长报告分段和进度模拟、ZIP 完整性通过。Android 编译、前台服务、持久恢复、MediaCodec 长音频处理、Small 推理及手机锁屏实测均待确认。没有引入未验证的 VLM 库。
